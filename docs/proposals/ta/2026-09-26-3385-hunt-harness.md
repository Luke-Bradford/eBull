## Splits and purge
Sessions are NYSE sessions.
- **discovery** 1990-01-02 → 2008-12-31; **validation** 2009-01-02 → 2021-06-28;
- **holdout** `HOLDOUT_BOUNDARY` → an end session frozen in the holdout declaration. It is a **corroboration**
  window, already partly seen (#3384 Finding 5).

**Timeline (construction).** Formation session t; entry session e = t + lag; exit session x = e + h − 1; points
`entry_point`, `exit_point` ∈ {open, close}. Integers lag ≥ 1, h ≥ 1. The hold must have positive duration: with
h = 1 only open → close is allowed. Exit is always at x; there is no late exit or delayed entry.
- **Horizon cap (construction):** lag + h − 1 ≤ 63, so x ≤ t + 63 and every label sits inside the 63-session embargo.
- **Purge:** an observation belongs to split S only if t, e and x all fall in S.
- **Embargo:** formations in the first 63 sessions of validation and of holdout are dropped, not moved.
- **Fitting.** A fitted value is a **literal constant in the spec**. At run time a signal may use only causal
  transforms of data ≤ t. Validation and holdout specs carry constants fitted on discovery only.

**Survivor conditioning** (#3384 Finding 1): every series trading before 2013-06-21 survives to at least that date.
Every spec carries a required `survivor_bias_direction` ∈ {`favours_arm`, `favours_control`, `unknown`} with a
reason, and every validation readout reports the sub-spans before and after 2013-06-21 side by side (descriptive;
selecting one is a new trial).

## A trial
`TrialSpec` is a frozen dataclass, validated on construction (field domains, integer types, nested types). Nested
values are tuples or frozen mappings. Canonical JSON: sorted keys, compact separators, integers as JSON integers,
floats as `{"f": <shortest round-trip repr>}` so a float never collides with a string, non-finite values refused.
- **`candidate_sha256`** covers what defines the hypothesis and its data: signal id and code hash, sign,
  selection, lag, h, points, constants, weighting, lane, `universe_identity`, `calendar_identity`, `cost_model_id`,
  `harness_model_id`. It excludes `hunt_id`, `family`, `split` and text fields, so relabelling cannot make a
  candidate new. One `evaluate` row per (candidate, split), programme-wide.
- **`spec_sha256`** = candidate plus `hunt_id`, `family`, `split`.

| field | content |
| --- | --- |
| `hunt_id`, `family` | e.g. `hunt-1`, `overnight_intraday` |
| `signal_id`, `signal_code_sha256` | see "Signals" |
| `sign` | +1 selects the top of the score, −1 the bottom. It never flips the test: the prediction is always that the selected long book beats the control. `mechanism` and `competing_explanation` are text |
| `selection` | fraction f ∈ (0, 0.5]; count ⌈f · N⌉ of the N scored names, ties at the cut all included and counted |
| `lag`, `h`, `entry_point`, `exit_point` | as "Timeline" |
| `constants` | the fitted literals, passed to the signal |
| `weighting` | `equal` only |
| `lane` | `real_stock_long_x1` only (see "Lanes") |
| `universe_identity` | `validated_ids_sha256`, price-archive identity (incl. its dividend and split tables), `termination_identity` |
| `cost_model_id`, `harness_model_id` | the frozen models |
| `survivor_bias_direction` | as above |

**Binding.** Before computing, `evaluate` recomputes the signal module's hash, the universe identity from the live
archive, and reads the running `COST_MODEL_ID` / `HUNT_HARNESS_MODEL_ID`. Any mismatch with the spec refuses
(`identity_mismatch`) before registration.

**Signals.** `signal(t, view, constants) -> {series_id: score}` in `app/services/hunt_signals/<family>.py`. The
view holds bars ≤ t for the eligible names, **rebased so each series' close on t equals its as-traded close on
t**; a later split cannot change a price level the signal sees.
- A test restricts `hunt_signals` modules to an import allowlist (stdlib `math`/`statistics`/`dataclasses`/
  `typing`, numpy, the view type): no DB driver, reader, file or network I/O, or randomness. The code hash covers
  the module, not the view implementation, the stdlib or numpy.
- A look-ahead probe test drives a signal that indexes past t.
- ⚠ Code-review enforcement, not a sandbox (residual).
- A missing or non-finite score makes the name **unscored** on t (below).

**Eligibility (construction)**, the same for both books, bars ≤ t only (#3384 Input 4). A series is eligible on t
when it is in the admitted set, has a bar on t, and that bar is valid: O, H, L, C finite and > 0; L ≤ min(O, C);
H ≥ max(O, C); volume finite and > 0; H > L. Per formation the harness counts each exclusion reason and the unscored
names.

## Registration: the log comes before the number
New migration (next free number), both tables append-only by trigger (the `sql/264` pattern):
- **`hunt_trials`**: `hunt_trial_id`, `hunt_id`, `family`, `split`, `candidate_sha256`, `spec_sha256`, `spec` jsonb,
  `harness_model_id`, `registered_by`, `purpose` ∈ {`evaluate`, `recorded_after`}, `floor` bool, `note`,
  `registered_at`. Partial UNIQUE (`candidate_sha256`, `split`) WHERE `purpose = 'evaluate'`; UNIQUE (`note`)
  WHERE `purpose = 'recorded_after'` (idempotent recording).
- **`hunt_trial_outcomes`**: `hunt_trial_id` (FK, unique), `status` ∈ {`computed`, `refused`, `abandoned`},
  `statistics` jsonb (every cell, with refusal reasons), `active_series` jsonb (canonical cell, fixed grid),
  `access_id` and `declaration_sha256` (NULL only for discovery), `outcome_sha256`, `computed_at`.

`status = refused` means the base canonical cell refused; other cells' refusals live in `statistics`. A statistical
refusal is an outcome. An infrastructure error (DB, I/O, a bug surfacing as an exception) is not: it propagates,
writes no outcome, and the registered trial is retried. `abandoned` is written only by a reviewed script naming the
trial and the reason; it counts as refused.

**One programme lock.** A session-level advisory lock for the whole hunt programme, taken first by `evaluate`,
recording, freezes and readouts, held until the outcome is committed and released in `finally` (the connection is
not returned to a pool while held). The audited door's own trial lock is taken after it. Everything in the
programme is therefore serial; that is acceptable for a single-machine research harness and removes every
cross-hunt race.

`hunt_harness.evaluate(conn, spec, *, registered_by)`, in order:
1. Take the programme lock.
2. **Refuse without registering** (no search): identity mismatch; unpriced lane; refused timeline; a
   `recorded_after` row for this candidate in this split (the split is burned); hunt in `HUNT_CLOSED`; discovery
   after the hunt's validation declaration froze (`discovery_closed`); for validation and holdout, a spec not pinned
   in the frozen declaration (`spec_not_in_declaration`, recorded through `sql/340` under the door's lock, as
   `result_ledger` orders it).
3. If an outcome exists for (candidate, split): discovery returns it; validation re-passes the door and
   `verify_outcome_access_provenance` and returns it; holdout returns nothing (release barrier).
4. If a registration exists without an outcome, reuse it (a retry after a crash: the same search against the same
   identity-bound data). Otherwise, for discovery, refuse `budget_exhausted` if the hunt's discovery rows (both
   purposes) are at `HUNT_BUDGETS[hunt]`; else insert. **Commit** before any price read.
5. Validation and holdout: pass the audited door; its access row commits before the price read.
6. Compute; for validation and holdout verify provenance; write and commit the outcome; release the lock.

**M is counted from `hunt_trials`, not outcomes.** A crashed or abandoned trial is a search. Exploratory charts
count too (programme rule 2), so the harness is the only sanctioned route to an outcome-bearing number on research
prices for a hunt.
- `tests/test_sealed_outcome_scripts_are_gated.py` is extended: a module under `scripts/` or `app/services/hunt*`
  that imports a research price reader fails unless it is `hunt_harness` or already on that test's gated list.
  Indirect readers, notebooks and shells are outside it (residual).
- A look outside the harness is recorded as `recorded_after` rows, one per variant the recorder states was looked
  at; if unknown, one row with `floor = true`. `note` identifies the look. It counts in M and in the budget, and
  burns that candidate's split.

**Budget and closure.** `HUNT_BUDGETS` (discovery rows per hunt, both purposes) and `HUNT_CLOSED` (hunt → terminal
readout) are operational constants changed only by reviewed PRs. A hunt with no budget entry refuses registration.
A budget is set once, by the #3387 PR that opens the hunt; raising it is a new hunt. A hunt closes:
- when discovery closes with no candidate declared, or the validation batch completes with no `PASS`: **"no
  demonstrated edge"**;
- otherwise after its holdout readout, reporting it.

The closure PR lists each candidate's verdict, so a control failure, a refusal and an undetermined result stay
distinct, and its test checks the listed verdicts against the stored outcomes.

**Trial register (#2829).** Slice 1 extends `DeclaredTrial`'s contract (its docstring and test) with two cases for
`searches > 1`: **log-backed** (ids durable in `hunt_trials`; `evidence` gives the query, a closing timestamp from
the DB clock, and the sha256 of the ordered id list, whose length must equal `searches`) and **declaration-backed**
(`evidence` = the declaration doc's sha256; `searches` = its pinned specs). A hunt with no searches in a split has
no entry. Entries `hunt-<n>-<split>`:
- **discovery:** added by the PR closing discovery; `EXACT`, or `FLOOR` if any counted row has `floor = true`;
- **validation / holdout:** added by the declaration PR before the freeze (the prospective claim
  `freeze_preregistration` requires).
- **Tripwire, at every freeze:** the discovery entry's id-list hash and count equal the log's at its timestamp, and
  no discovery row is newer; each declaration entry's count equals its pinned specs. Otherwise the freeze refuses
  `register_disagrees_with_log`. Discovery screening readouts do not refuse; they are labelled `register_pending`.

## The audited door: validation and holdout
- **Validation.** A hunt's batch is one `PreregDeclaration` (`strategy_id = hunt-<n>-validation`, `v1`), claimed by
  `hunt-<n>-validation` via `declared_for`, frozen from `main` by `freeze_preregistration` before the look. Its
  hashed doc pins every candidate's `spec_sha256`, M, V[SR] with the trial ids it came from, the BY readout that
  flagged each candidate, and the power output. Only candidates with a discovery `evaluate` row, each once, and
  not pinned by another hunt. The freeze refuses while any of the hunt's discovery registrations lacks an outcome
  (computed, refused or abandoned), so V[SR]'s population is complete. Freezing closes the hunt's discovery.
  Validation verdicts carry `previously_examined` (#3384 Finding 5).
- **Holdout.** At most one declaration per hunt (`hunt-<n>-holdout`, `v1` only), freezable only once every pinned
  validation spec has an outcome, and only if at least one is a `PASS` (otherwise the hunt closes). It pins every
  validation `PASS` together, the holdout end session (≤ the archive's last session, else refused), and reuses
  validation's frozen V[SR] and M plus its own pinned specs.
  `evaluate` on holdout writes outcomes but **returns none**. `holdout_readout(hunt)` returns the verdicts, labelled
  `corroboration_partly_seen`, only when every pinned spec has an outcome; a pinned spec that cannot be computed is
  retried, or marked `abandoned` by the reviewed script, and the readout then shows it `NOT_PASS_REFUSED`. Direct
  table reads are not barred (residual); the readout is the only sanctioned route.
- **Atomicity.** Freeze-time numbers are computed under the hunt lock in one REPEATABLE READ snapshot.

## The evaluator: arm minus matched control
**Books.** For each formation t:
- the **control cohort** C(t) = every eligible **scored** name. Restricting to the signal's own domain keeps its
  history requirement out of the active return; the edge measured is *within* that domain (residual);
- the **arm cohort** A(t) ⊆ C(t) = the selected names. With ⌈f · N⌉ ≥ 1, A(t) is non-empty whenever C(t) is;
- same lag, h, points, weighting, lane and costs: the "same construction without the signal" (#2908/#2901).

**Fixed grid.** The active series is defined on **every** session from the first to the last session on which a
calendar-usable formation (inside the split, past the embargo, purge satisfied; no price involved) can hold a
position. T = the number of those sessions, known from the calendar before any price is read. A split with no
calendar-usable formation refuses (`empty_grid`).

**Calendar-time series (construction, after JT §I).** Each book has h slots with fixed weight 1/h. On session d,
slot k holds the cohort formed at t_k = d − lag − k (k = 0 … h − 1) if that formation is calendar-usable and C(t_k)
is non-empty; otherwise the slot is **idle** and returns 0 in both books. Book return r(d) = (1/h) Σ_k r_k(d). The
fixed 1/h across slots is the JT convention and implies uncosted rebalancing between slots, in both books
(residual; turnover can differ between the books, so the bias is not signed).

**Within a cohort: buy-and-hold on value factors.** Equal amounts go into each entered position at entry. Each
position carries a value factor V_i(d) ≥ 0; the cohort's return on d is Σ V_i(d) / Σ V_i(d−1) − 1 over its entered
positions, and 0 once Σ V_i(d−1) = 0 or no position is live. This is self-financing: nothing is reallocated after
entry, and a stale position keeps its value.

**A position's value factor** (ratio-basis corrected prices; costs as fill prices via `cost_model.buy_price` /
`sell_price`, so every factor is a ratio of non-negative prices and is ≥ 0; computed as factors, never as
returns minus one):
- **entry** at e, at `entry_point`: V_i = P(e) / buy_price(P(e)). A close entry has no price change on e;
- **each later session with a bar:** V_i(d) = V_i(prev) · (close(d) + D) / close(prev), D = every cash dividend with
  ex-date in (prev, d], each divided by the split ratio between its ex-date and d, so all amounts sit on d's share
  basis;
- **a session without a bar:** V_i(d) = V_i(d−1). The next bar's factor spans the gap, dividends included;
- **exit at x**, at `exit_point`: the last step uses open(x) or close(x) and the fill is sell_price. If the name has
  no bar on x it is exited **on x** at its last available close (a stale mark, no future information), sell side
  applied;
- **no bar at e:** the position is never entered and never charged; the cohort is the positions that were entered.
  Both books apply the same rule. A cohort with none is idle;
- h = 1 (open → close): one factor, open(e) buy fill to close(e) sell fill.

**Termination and censoring.** Terminating series are those the admitted selection marks terminating
(`AdmittedSeries.termination` is not `None`, #3362); their terminal bar is the stored `last_bar`, never the loaded
series' own end. For an entered position still held after its terminal bar's close, the factor becomes
V_i · f on that session, f the policy's terminal fraction, and stays constant thereafter (no exit cost; the
haircut applies to the whole position value, dividends already credited included, a residual). A live series is
never haircut: a trailing gap is a run of sessions without a bar, marked stale, and exited at x as above.
Classification is the frozen selection's, so an archive extension cannot reclassify within a trial.

**Ruin.** Factors are ≥ 0 by construction. A book's slot average cannot compound past zero. A slot whose cohort value
reaches 0 is idle from the next session. `book_ruin` refuses the cell when r(d) ≤ −1 + 10⁻⁹, i.e. a near-total
single-session loss of the whole book, which the harness treats as a construction error, not a result.

**Active series.** a(d) = r_A(d) − r_C(d) on the fixed grid, net of costs. A no-signal spec (A ≡ C) gives a(d) ≡ 0
exactly under base cost.

**Descriptive tilts (not gating):** the slope of a on r_C, and the arm-minus-control mean of log as-traded price and
of trailing 63-session volatility (residual: tilts are reported, not neutralised).

## Inference
**Cells.** Each trial is computed per termination policy × {with, without dividends}, at base and at stress cost.
The **canonical cell** is base, with dividends, `zero_recovery`; it alone is stored as `active_series` and feeds
V[SR].

Per cell:
- **Lag (construction):** L = max(2h, ⌊4(T/100)^{2/9}⌋). The 2h floor covers the overlap of h cohorts and a
  margin; dependence beyond it is possible (residual).
- **HAC t** = mean(a) / NW standard error at L.
- **p** = `student_t_cdf`(−t, df), df = ⌊T / L⌋ − 1, the number of non-overlapping L-blocks (construction; heavier
  tails than the normal, not a finite-sample correction). `student_t_cdf` loses precision deep in the tail and can
  return 0 or a tiny negative: p is clamped to [0, 1], and any p < 10⁻¹² is recorded as `< 1e-12`. The t > 3 gate
  does not use p.
- **Statistical refusals (construction, frozen):** T < 10·L (`short_sample`); fewer than 30 formations with at
  least one **entered** arm position, counted greedily from the first such formation, each at least h sessions
  after the last counted (`sparse_arm`); zero variance or a non-positive NW variance (`degenerate_variance`); any
  non-finite intermediate anywhere in the cell (`non_finite`). A `None` or a documented `ValueError` from a shared
  statistics function is `Refused`; any other exception is an infrastructure error (propagates, no outcome).

**DSR (validation and holdout candidates only):**
- SR, skew and raw kurtosis from `trade_moments(a)`;
- T_eff = min(T, T · γ̂₀ / Ŝ_NW) at L (construction: a mean-based effective sample, applied to a Sharpe ratio;
  the paper assumes independence and offers no correction; negative dependence is not credited here, though the
  HAC t itself can still benefit from it — residual). T_eff ≤ 30 refuses (`short_effective_sample`);
- **V[SR_n]:** the ddof=1 variance of the canonical-cell per-observation Sharpe over every discovery `evaluate`
  trial **of this hunt** with an outcome. A Sharpe is computed for every outcome whose canonical series is finite
  with non-zero variance, whether or not its other statistics refused (declaration freeze requires every
  registration to have an outcome, so the population is complete). Fewer than 10 such trials refuses
  (`trial_population_too_small`). **Floor (construction):** V[SR] = max(measured, 1 / T̄), T̄ the population's mean
  T. 1/T is the sampling variance of a per-observation Sharpe estimate under zero edge, so clones or near-identical
  trials cannot collapse the deflation. Frozen in the declaration with the trial ids;
- **N̂ = M, no correlation discount:** the shared DSR is called with `average_correlation = 0.0`, which equation (9)
  maps to N̂ = M. A.3: *"using M instead of N will overstate E[max{SR_n}]"*, conservative whenever the true average
  correlation is ≥ 0 (a negative average across hundreds of trials is not credited; residual). The call passes the
  new axis id, M, and the register version;
- **M** = M_inh + every `hunt_trials` row across all hunts, splits and purposes + every pinned spec (in the
  declaration being frozen and in every earlier frozen declaration) that has no `hunt_trials` row yet. A pinned but
  unevaluated spec is counted as reserved (conservative); nothing is counted twice because a (candidate, split)
  has at most one `evaluate` row programme-wide;
- id `hunt-calendar-active-dsr-v1` (the axis differs from `c6-deflated-sharpe-v1`).

**BY (programme-wide discovery screen).**
- m = M_inh + every discovery row across the programme at readout time;
- a trial's p is the **largest** base-cost p over its policy × dividend cells (every cell must clear the screen);
  p = 1 if any base cell refused, if it has no outcome, or for an inherited search;
- reject the largest k with p₍ₖ₎ ≤ k·q / (m·c(m)), q = 0.05, and flag every p ≤ p₍ₖ₎; if no k qualifies, flag
  nothing;
- recomputed on every readout; a flag counts only in the readout pinned by a validation declaration.
- **Claim:** BY here is a screen deciding which candidates may be declared. Theorem 1.3 assumes a fixed family of
  valid p-values; this programme is sequential and adaptive and its inherited searches have no p-values, so the
  nominal FDR is **not** guaranteed (residual). Validation's t and DSR bars are the gate.

**Per-regime readout** (descriptive): mean(a) and session count per `classify_regimes` label of session d. No t.

## Verdicts
**Discovery** issues no verdict: statistics plus a BY flag.

**Validation and holdout**, per candidate. Base cells = policy × dividends at base cost; stress cells likewise, where
only t and mean(a) are computed (no DSR). A refused stress cell counts as a failed stress cell. First match wins:
1. `NOT_PASS_REFUSED`: any base cell refused (reasons listed).
2. `PASS`: every base cell has t > 3.0, DSR ≥ 0.95 and mean(a) > 0, and every stress cell has t > 3.0 and
   mean(a) > 0.
3. `PASS_CONTINGENT`: base as 2, stress not. **No capital, no holdout.**
4. `FAIL_CONTROL`: mean(a) ≤ 0 in every base cell.
5. `UNDETERMINED`: mean(a) > 0 in every base cell, and each base failure is t or DSR only. Never labelled "no edge"
   (programme rule 3).
6. `NOT_PASS_MIXED`: anything else, failures listed.

## Power, before each validation and holdout look
`scripts/measure_3385_power.py --declaration <doc>` reads **stored discovery outcomes only** (the candidate's
canonical `active_series`), reads no prices, and is a readout, not a search. From the stored series it takes Ŝ_NW
at the target split's L. T_x is the target split's fixed-grid length, from the calendar.

It prints, for the canonical cell's t bar only, the minimum detectable annualised active mean at 50% and 80% power
under a normal approximation with Ŝ_NW treated as known: (3 + z)·√(Ŝ_NW / T_x)·252, z ∈ {0, 0.8416}. It also
prints whether T_x clears the `short_sample` floor. The output says, in words, that it is not power for DSR, for
the other cells, or for the joint PASS, and that Ŝ_NW is assumed to carry over from discovery. The discovery effect
is selection-biased upward, so no verdict is predicted from it. The declaration copies the output; the run
re-executes the script on the stored outcome hashes pinned in the declaration and refuses on any difference at 6
significant figures.
