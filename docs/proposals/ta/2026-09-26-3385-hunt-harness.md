## Splits and purge
Sessions are NYSE sessions (`us_market_status`).
- **discovery**: 1990-01-02 → 2008-12-31.
- **validation**: 2009-01-02 → 2021-06-28.
- **holdout**: `HOLDOUT_BOUNDARY` → the last archive session, **frozen in the holdout declaration** (a later archive
  extension is a new look, not part of this one). This is a **corroboration** window, already partly seen (#3384
  Finding 5).

**Timeline (construction).** A formation session t has entry session e = t + lag and exit session x = e + h − 1, with
`entry_point`, `exit_point` ∈ {open, close}. `lag` and `h` are integers, lag ≥ 1, h ≥ 1. The hold must have positive
duration: h = 1 is allowed only with entry = open and exit = close. Any other h = 1 combination is refused.
- **Horizon cap (construction):** x ≤ t + 63, i.e. lag + h − 1 ≤ 63. Larger values are refused. This keeps every
  label inside the 63-session embargo; the embargo citation does not itself fix the cap.
- **Purge:** an observation belongs to split S only if t, e and x all fall in S.
- **Embargo:** formations in the first 63 sessions of validation and of holdout are dropped, not moved.
- **Fitting.** Any fitted value (threshold, constant, normaliser parameter) is a **literal field of the spec**, not
  computed at evaluation time, except causal transforms that use only data ≤ t (rolling normalisers, ranks and
  winsorisation within date t). Validation specs carry constants fitted on discovery only. Holdout specs carry the
  same constants: no refit on validation.

**Survivor conditioning** (#3384 Finding 1): every series trading before 2013-06-21 survives to at least that date.
So the whole of discovery, and validation up to 2013-06-20, is survivor-conditioned.
- Every trial spec carries a required field, `survivor_bias_direction` ∈ {`favours_arm`, `favours_control`,
  `unknown`}, with a one-line reason. It has no default.
- Every validation readout reports the pre-2013-06-21 and post-2013-06-21 sub-spans side by side. This is
  descriptive only: selecting either sub-span is a new trial.

## A trial
`TrialSpec` is a frozen dataclass. Two hashes, both sha256 of canonical JSON (sorted keys, compact separators; the
`PreregDeclaration.sha256` convention):
- **`candidate_sha256`** over the fields that define the hypothesis: signal id and code hash, sign, selection, lag,
  h, points, weighting, lane, fitted constants, `cost_model_id`, `harness_model_id`. It **excludes** `hunt_id`,
  `family`, `split` and every label, so relabelling a candidate cannot make it new.
- **`spec_sha256`** over the candidate plus `hunt_id`, `family`, `split`, `universe_identity`.

A validation or holdout spec must have the `candidate_sha256` of a discovery row; only split-bound fields may differ.

| field | content |
| --- | --- |
| `hunt_id`, `family` | e.g. `hunt-1`, `overnight_intraday` |
| `signal_id`, `signal_code_sha256` | see "Signals" |
| `sign` | +1 or −1: **selects** the top (+1) or bottom (−1) of the score. It never flips the test: the prediction is always that the selected long book beats the control. `mechanism` and `competing_explanation` are text |
| `selection` | fraction f ∈ (0, 0.5]. Count = ⌈f · N⌉ of the N scored names; ties at the cut are **all included** (the #2240 threshold-row prevention entry) and counted |
| `lag`, `h`, `entry_point`, `exit_point` | as "Timeline" |
| `constants` | the fitted literals, as "Fitting" |
| `weighting` | `equal` only in v1 |
| `lane` | `real_stock_long_x1` only in v1 (see "Lanes") |
| `split` | discovery, validation or holdout |
| `universe_identity` | `validated_ids_sha256` + price-archive identity + `termination_identity` |
| `cost_model_id`, `harness_model_id` | the frozen models |
| `survivor_bias_direction` | as above |

**Signals.** A signal is a function in `app/services/hunt_signals/<family>.py`, called as `signal(t, view)` where
`view` holds bars ≤ t close for the eligible names and nothing else. `signal_code_sha256` hashes that module file.
- A test restricts `hunt_signals` modules to an import allowlist (stdlib `math`/`statistics`/`dataclasses`/`typing`,
  numpy, and the view type). No DB driver, no reader, no file or network I/O, no randomness. The hash then covers the
  signal's whole behaviour except numpy's.
- A look-ahead probe test drives a signal that indexes past t and asserts it cannot.
- ⚠ This is **code-review enforcement, not a sandbox.** An in-process callable could still reach module globals.
  Declared residual.
- A score that is missing or non-finite makes the name **unscored** on t. Unscored names leave both books (below).

**Eligibility (construction)**, identical for arm and control, using only bars ≤ t (#3384 Input 4). A series is
eligible on t when all hold:
- it is in the admitted set and has a bar on t (see the admission residual);
- that bar is valid: open, high, low, close finite and > 0; low ≤ min(open, close); high ≥ max(open, close);
  volume finite and > 0; high > low (non-zero range).

Per cohort the harness counts each exclusion reason and the unscored names.

## The audited door: validation and holdout
- **Validation.** Only candidates from discovery, each tried once. A hunt's validation batch is one `PreregDeclaration`
  (`strategy_id = hunt-<n>-validation`, version `v1`):
  - claimed by the register entry `hunt-<n>-validation` via `declared_for`;
  - frozen by `freeze_preregistration` from `main` before the look;
  - a hashed declaration doc pins every candidate's `spec_sha256`, M and its components, the register version, V[SR]
    and ρ̂ with the ids of the trials they came from, the BY readout that flagged each candidate, and the power
    output.
- **Holdout.** At most **one** declaration per hunt: `strategy_id = hunt-<n>-holdout`, version `v1` only (a `v2` is
  refused), claimed by `hunt-<n>-holdout`. It covers every validation `PASS` together, never one candidate at a time,
  and pins the same items plus the holdout end session. The readout is emitted only once every pinned spec has an
  outcome; there is no partial readout. It is labelled `corroboration_partly_seen`.
- **Atomicity.** Freeze-time numbers (log counts, BY flags, M, V[SR], ρ̂) are computed in one REPEATABLE READ
  snapshot under an advisory lock that registration also takes, so no row lands between them.

## The evaluator: arm minus matched control
**Books.** For each formation t in the split:
- the **control cohort** C(t) is every eligible **scored** name on t. Restricting to scored names keeps the signal's
  own domain (e.g. its history requirement) out of the active return;
- the **arm cohort** A(t) ⊆ C(t) is the selected names;
- both have the same lag, h, entry and exit points, weighting, lane and costs. This is the "same construction
  without the signal" of the #2908/#2901 lesson.

**Calendar-time series (construction, after JT §I).** Each book has h slots. On session d, slot k holds the cohort
formed at the t whose hold covers d. The book return is r(d) = (1/h) Σ_k r_k(d), a fixed 1/h per slot:
- **Within a slot, buy-and-hold:** equal amounts at entry, weights then drift with returns. No intra-cohort
  rebalancing, so the only trades are the entry and the exit, which is all the cost model charges.
- **Across slots**, the fixed 1/h averaging is the JT convention and implies rebalancing between slots. That
  rebalancing is **not costed**, identically in both books. Declared residual.
- **A slot with no cohort** (split start, embargoed formation, cohort already exited, or C(t) empty) returns 0 in
  **both** books: idle cash at zero return, so it adds nothing to the active return.
- **Empty arm slot:** if A(t) is empty but C(t) is not, the arm's slot holds C(t), costed as the control is, so it
  contributes exactly zero active return. Exposure then matches the control, and no cash drag counts as signal.

**Daily marking** of one position, on the ratio-basis corrected series:
- entry at open on e: day-e return close(e)/open(e) − 1. Entry at close on e: no day-e return; the first is day e+1;
- inner days: close(d)/close(d−1) − 1;
- exit at close on x: last return close(x)/close(x−1) − 1. Exit at open on x: last return open(x)/close(x−1) − 1,
  then zero for the rest of x;
- **missing bar** inside the hold (halt, gap): 0 that day; the next valid bar's return spans the gap from the last
  valid price. A name is **never dropped** after formation, so membership never depends on later data;
- **exit bar missing:** exit at the first valid bar after x, booked on that session. A name without a valid bar at e
  enters at its first valid bar before x, or not at all (cash, entry cost refunded);
- **dividends:** cash per share divided by the same split ratio as the price, credited at the ex-date's open to a
  position held at the prior close. #3384 Finding 2 leaves the ex-date semantics unverified, so every readout runs
  **with and without** dividends. The pair brackets only that choice, not a misdated or misscaled dividend (residual);
- **termination:** the series' last archive bar is its last close. The terminal value (last close × the policy's
  terminal fraction) is booked on the next session. The slot's share of that position is cash at zero return until
  the cohort exits; nothing is redistributed, and no exit cost is charged on it. A series whose last bar is the
  archive's last bar is **censored, not terminated**: marked at that close, no haircut;
- **ruin:** position returns are ≥ −100% by construction. A book return of −100% on any session refuses the trial
  (`book_ruin`); since r(d) is an average of slots, not a compounded NAV, nothing propagates past it.

**Active series.** a(d) = r_A(d) − r_C(d), net of costs on both books, one value per session d on which at least one
slot is live in either book. T is the length of this series. A no-signal spec (A ≡ C) gives a(d) ≡ 0 exactly under
the base cost arm.

**Descriptive tilts (not gating):** the slope of a on r_C, and the arm-minus-control mean of log as-traded price and
of trailing 63-session volatility. Active return can carry systematic tilts; a mechanism claim needs the step-8
construction. Declared residual.

## Inference
**Variants.** Each trial is computed per termination policy × {with, without dividends} × {base, stress} cost. The
**canonical variant** is base cost, with dividends, `zero_recovery`. It alone feeds V[SR], ρ̂ and `active_series`.

For each variant, with T and a(d) as above:
- **HAC t (construction):** L₀ = max(h, ⌊4(T/100)^{2/9}⌋). t is computed at L₀ and at 2·L₀, and the **smaller** is
  used. Dependence need not stop at h, and a Bartlett floor at h down-weights lags near h. The pair is a
  sensitivity, not a guarantee (residual).
- **p-value:** one-sided, p = 1 − `student_t_cdf`(t, df), df = max(1, ⌊T_eff⌋ − 1). It is heavier-tailed than the
  normal and is still asymptotic (residual).
- **DSR** on the daily active series:
  - SR, skew and raw kurtosis from `trade_moments(a)`;
  - T_eff = T · γ̂₀ / Ŝ_NW at L₀ **(construction)**: the ratio of the IID variance of the mean to its HAC variance.
    It is a mean-based effective sample applied to a Sharpe ratio. The paper assumes independence and gives no
    dependence correction, so its worked answers cannot validate this. If T_eff > T (negative dependence) it is
    capped at T; negative dependence is not credited;
  - **V[SR_n]:** the ddof=1 variance of the canonical-variant per-observation Sharpe over the hunt's **discovery
    trials with an outcome** under the same `harness_model_id`. Crashed, refused and abandoned rows count in M but
    have no Sharpe; their number is reported next to V. This is every measured screen, not a survivor subset;
  - **ρ̂:** equation (8) over pairwise correlations of those trials' canonical active series, each pair on its
    common sessions. A pair with fewer than 252 common sessions, or a constant series, is excluded and counted. A
    negative ρ̂ is floored at 0;
  - **N̂ = M_inh + [ρ̂ + (1 − ρ̂) · M_hunt]**. Equation (9) applies only to the hunt's trials, where ρ̂ was
    measured; inherited searches enter undiscounted (ρ = 0), which the paper's A.3 notes is conservative;
  - M_hunt = every `hunt_trials` row across all hunts and splits at freeze time, **plus** the pinned specs about to
    be evaluated. M_inh as below. Both frozen in the declaration;
  - id `hunt-calendar-active-dsr-v1`, because the axis differs from `c6-deflated-sharpe-v1` (trade axis).
- **Refusals (construction).** Every `None`, exception or non-finite value from a shared function becomes
  `Refused(<reason>)`; none reaches a verdict silently. Specifically refused: T < 10 · 2L₀ (`short_sample`); fewer
  than 30 formations with a non-empty arm (`sparse_arm`); T_eff ≤ 30 (`short_effective_sample`); γ̂₀ = 0 or Ŝ_NW ≤ 0
  (`degenerate_variance`); fewer than 2 trials, or V[SR] = 0, in the V/ρ̂ population (`degenerate_trial_population`).
  These floors are not published; they are frozen here.

**BY (programme-wide discovery screen).**
- m = M_inh + every discovery row in `hunt_trials` across the programme at readout time.
- The p for a trial is the **largest** p over its policy × dividend cells at base cost, so passing the screen needs
  every cell (an intersection-union choice; picking the smallest would break joint robustness).
- Inherited searches, and discovery rows without an outcome, enter as p = 1.
- Rejection: the largest k with p₍ₖ₎ ≤ k·q / (m·c(m)), q = 0.05; flag every p ≤ p₍ₖ₎.
- Recomputed on every readout, never reset per family or hunt; a flag can be withdrawn as m grows. Readouts are
  computed, not stored, except the snapshot pinned in a declaration.
- **What it claims, and not more.** BY is a *screen* that decides which candidates may enter a validation
  declaration. Theorem 1.3 holds for a fixed family of valid p-values. This programme is sequential and adaptive, and
  its inherited searches have no p-values, so the nominal FDR is **not** a guarantee here (residual). A flag counts
  only at the moment a validation declaration freezes, and that readout's m is pinned. A later withdrawal is
  reported, but does not undo a frozen declaration. Validation's own bars (t, DSR) are the gate.

**Per-regime readout** (descriptive, never gating): the session d's `classify_regimes` label. It reports mean(a)
and session count per label only. No t is computed on non-contiguous sessions, and nothing is selected from it.

## Verdicts
**Discovery** issues no verdict. Its readout is statistics plus a BY flag. Discovery is not evidence.

**Validation**, per candidate, over its cells (policy × dividends) at base cost, then at stress. First match wins:
1. `NOT_PASS_REFUSED`: any cell refused, at base or stress, with the reasons.
2. `PASS`: at base cost, **every** cell has t > 3.0, DSR ≥ 0.95 and mean(a) > 0, **and** every stress cell has the
   same.
3. `PASS_CONTINGENT`: base as 2; at least one stress cell fails. **No capital, no holdout.**
4. `FAIL_CONTROL`: mean(a) ≤ 0 in every base cell.
5. `UNDETERMINED_AT_THIS_POWER`: mean(a) > 0 in every base cell, and every failed base condition is t or DSR. Never
   labelled "no edge" (programme rule 3).
6. `NOT_PASS_MIXED`: anything else, with every failed condition listed.

## Power, before each validation and holdout look
`scripts/measure_3385_power.py --declaration <doc>` reads **stored discovery outcomes only**: the candidate's
canonical `active_series` from `hunt_trial_outcomes`. It is a readout, not a search, and reads no prices from any
split. From that series it takes σ̂, Ŝ_NW at L₀ and the fraction of sessions with a non-empty arm.

It prints the minimum detectable annualised active mean at the t = 3 bar, for 50% and 80% power:
(3 + z)·√(Ŝ_NW / T_x)·252, z ∈ {0, 0.8416}. T_x is the number of sessions the target split's series will have: its
calendar sessions after embargo, less the horizon run-in. Every session is an observation, because empty slots are
zero rather than missing.
- This is power for **the t bar alone**, not for DSR or the joint PASS condition. It must be labelled so.
- It assumes the discovery Ŝ_NW carries over to the target split, across a coverage and survivorship change. That is
  an assumption, stated in the output, not assessed.
- The discovery effect is selection-biased upward, so no verdict is predicted from it.
- The declaration copies the output. The run re-executes the script against the stored outcome hashes pinned in the
  declaration and refuses on any difference after rounding to 6 significant figures (the #2901 rule).

## Lanes and cost model (`hunt-cost-v1`)
Costs are charged **per side**, on each position's entry and exit, on both books. Today's tariff applied to 1990–2024
is a **labelled counterfactual**: every outcome carries `cost_regime = tariff-2026-counterfactual`.

| lane | status in v1 | charge |
| --- | --- | --- |
| `real_stock_long_x1` | **priced** | frozen half-spread band keyed on the as-traded entry price (`cost_band_for`), per side, plus any commission on the re-fetched fees page. A fixed per-order fee is converted at a declared notional per position (construction). Carry and FX are zero on this lane only under `COST_MODEL_ID`'s stated prerequisites (USD order, USD account, real settlement), which the lane declares and the outcome records |
| `stock_cfd_long_x1` | **unpriced → refused** | 0.15% per side + the band half-spread + 2¢/unit per side at an as-traded price ≤ $3 + (6.4% + benchmark)/365 per night, Friday ×3. The benchmark needs a point-in-time rate series (#3384 slice 2b / FRED ingest, programme step 6) |
| `stock_cfd_short_x1` | **unpriced → refused** | historical borrow availability and hard-to-borrow fees are not observable, and the programme doc requires an executable borrow rule, not an assumption |
| `index_cfd_hedge` | **unpriced → refused** | #2844 gross-exposure question (see "What this spec fixes") |

The price basis is **not hardcoded**: every run calls `cost_price_basis` on the archive and refuses unless it
returns `as_traded`. A refused lane fails before registration, so it costs no search: the `CARRY_CLOSURE` fail-closed
shape, a closure state, never a zero pretending to be a measurement.

**Stress arm (construction, a sensitivity, not a bound):** the arm's selected positions are charged
`UNKNOWN_NOMINAL_PRICE_BAND` (the maximum frozen band); control positions, and control positions copied into an empty
arm slot, keep the base band. Names already in the top band get no extra charge, and a real gap or illiquid state can
exceed it. Under stress a no-signal spec therefore shows a negative active return equal to the extra charge. That is
intended: a construction without an edge should fail stress.

## Declared residuals
- Tariff counterfactual. The band table is one summer's closing-hour quotes (`cost_model` limits 1–3), applied to
  1990. Inter-slot rebalancing is uncosted in both books.
- Survivor conditioning before 2013-06-21; its direction is declared per trial, not corrected. The admitted set is
  not point-in-time either: admission uses today's validated universe and #2721's asymmetric admission (#3384
  slice 1).
- Asymptotic inference: the t bar, the Student-t p-values and BY's nominal level inherit it. BY is a screen, not an
  FDR guarantee, in an adaptive programme with inherited searches that have no p-values.
- T_eff and the lag pair are constructions, not published corrections.
- M can only be a floor where the register is (its FLOOR entries). A DSR PASS is then an upper bound on significance,
  as the register already states.
- Signal isolation is by code review and an import test, not a sandbox. Notebooks and shells are outside the gated
  test.
- Active returns may carry size, volatility or beta tilts; they are reported, not neutralised.
- Dividends: the with/without pair brackets only inclusion, not misdating or misscaling.
- Validation is a previously examined window (#3384 Finding 5). Only forward paper confirms (programme step 8).

  windows and lengths.
- Equal-weight only. A survivor's construction (sizing, turnover band, hedge) is frozen later.
