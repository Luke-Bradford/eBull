# #2351 M2 — bind Item 403 lines to instruments

Status: spec, round 4 (2026-09-24; ckpt-1 rounds 1–3 = 58 / 42 / 19 findings, cited `#n` / `r2 #n` / `r3 #n`, in `var/census_2351/m2_ckpt1_r{1,2,3}.txt`). Parent: `2026-09-24-2351-def14a-class-grain-model.md`
(M1 shipped, #3358 `fa377e05`). M2 is **pure and measured**: no schema, no writer, no
reader change. M3 stores and switches readers.

## Question

For each stored legacy row `(instrument, accession, holder)` (`def14a_beneficial_holdings`,
fanned to every instrument sharing the issuer CIK), which figure should that instrument
show: the legacy figure, a different class line's figure, or none?

## Source rule

- **What a line is:** Item 403(a)/(b) (17 CFR 229.403) — amount and percent are figures of
  the class in *Title of class*. M1 exposes each line's class evidence; no instruction to
  Item 403 prescribes a multi-class layout (parent spec § Source rule).
- **What an instrument is:** the 10-K / 10-Q / 20-F cover's Section 12(b) table,
  `dei:Security12bTitle` + `dei:TradingSymbol` (Reg S-K Item 601(b)(104), Reg S-T Rule
  406; slice spec § Source rule). Titles are paired to symbols by the shipped
  `sec_cover_identity.cover_pairs` (shared context); no published rule guarantees one
  context per class, so a symbol paired with more than one title has no identity (r3 #1). Read with the shipped `resolve_cover` (newest original
  cover filed strictly before the proxy's filing date, ≤ 400 days, entity CIK must match)
  and cached in `sec_cover_12b_*`. An unregistered class (Alphabet / Meta Class B) is on
  no cover, so it is never an instrument's identity; it can still be a line's class.
- **Warrant / preferred instruments:** slice 2's rule and code, called unchanged (below).
- **No published rule** maps a proxy's class wording to a 12(b) title. The token
  comparison below is fixed **by construction** and frozen as
  `BINDING_RULE_VERSION = 1`.

## Inputs

Per accession with stored rows: the legacy rows per instrument, the body's M1
`item403_lines` (lines are already keyed to the parser's own `holder_name`, so holder
matching is M1's, #16), the issuer's instruments (siblings — every instrument whose single
sec CIK is the issuer's; `load_population` without its `>1` filter), and per instrument
its **identity**.

### Non-common instruments: the shipped decision, verbatim (r2 #1, #2, #6–#8, #12–#16, #41)

Warrant / preferred siblings are decided by the SHIPPED functions, called unchanged:
`decide` (slice 2) per accession and `extend_by_class` (slice 2b) per issuer, exactly as
`compute_desired` calls them, with its blocked sets (r3 #2). The issuer CIK of a legacy
row is the shipped one: the instrument's single sec CIK in `external_identifiers` (r3 #3,
parity). Their `Suppression` rows (witness, cover, carried-from)
are M2's `withhold:non_common_instrument` decisions and their evidence. M2 re-specifies
none of it, so parity is by construction; the Rule 13d-3 / preferred source argument is
slice 2's (slice spec § Source rule for "a warrant / preferred sibling …").

### Common identity (per instrument, per accession)

Only a class in the cover's 12(b) table has an identity; a class not listed there (12(g)
only, or unregistered) never does (r2 #4). **Cover:** shipped `resolve_cover`, unchanged
(≤ 4 newest original 10-K/10-Q/20-F of any sibling, strictly before the proxy's filing
date, ≤ 400 days; newest with 12(b) pairs whose entity CIKs include the issuer). The
ownership table's as-of date and corporate actions between cover and proxy are not
modelled — the shipped limit (#40, r2 #5). Transient read failure → `blocked`. No
identity is ever carried to another accession (#31–#37).

`key = symbol_key(symbol)`; the key must map to exactly one title `T` on the cover. Then:
- **Common only (both kinds below, r3 #4, #5, #6):** `T` must not match the shipped
  `_NON_COMMON_CAPTION` (preferred / warrant / right / unit / note / debenture), nor
  `depositar[yi]|depositor[yi]|\bAD[RS]s?\b` (an ADS is a ratio of an underlying, #28,
  #29), nor `UNSUPPORTED` = `\b[a-z]\s*-\s*\d|\b(?:class(?:es)?|series)\s+(?:[ivx]+|\d+)\b`
  (`Class A-1`, `A and A-1`, `Class II`). A match → `unresolved`.
- **Lettered:** the instrument is in shipped `usable_common_classes(siblings, cover)`
  (title common, exactly one shipped designator, that letter on no other cover title of
  ANY kind, one sibling key — r2 #11, #19). Identity `D = {(kw, letter)}` with `kw` from
  M1's `keyed_designators(T)`; if that set is not exactly one pair, or `T` minus its
  designator spans still contains `class(es)` / `series` (`Class A and Class A-1`,
  `Classes II and III`), → `unresolved` (r2 #9, #10).
- **Plain:** `title_kind(T) = common`, no `class` / `series` word in `T`, and no other
  cover title has `title_kind = common`. Identity `D = ∅`.
- Anything else → `unresolved`.

**Blocked (#36, #47, r2 #16):** exactly `compute_desired`'s sets — an unresolved or
undated accession is blocked for every sibling (`keep`), and an instrument holding one is
blocked on ALL its accessions (`keep_instruments`). A blocked row's decision is
`shipped`: its exposure is the shipped exposure.

## Line relation to a common identity

For a line ℓ, `E(ℓ)` = class evidence of its row class cells ∪ section label ∪ group
evidence (M1 fields; the union M1's `class_state` is computed on). Split into
designators `Dℓ` and kinds `Kℓ`.

- **neutral-forced** — M1 `class_state = conflict`; or any of the line's row class cells
  / section label contains `%` (a rate-bearing series, as shipped `row_class_label`, r3
  #9) or matches `UNSUPPORTED` (r3 #7); or `Kℓ` holds `warrant`, `unit`, `right` or
  `note` (r3 #8).
- **match** — `Kℓ ⊆ {common}` and either `Dℓ = D ≠ ∅`, or `D = Dℓ = ∅` and `Kℓ = {common}`.
- **mismatch** — `preferred ∈ Kℓ` (#37, #38); or `Kℓ ⊆ {common}`, `Dℓ = {(kw, x)}`,
  `D = {(kw, y)}`, `x ≠ y`. A plain identity has no designator mismatch: it requires no
  other common title on the cover, so a lettered line there is neutral (#3, r3 #10).
- **neutral** — everything else, incl. `Class A` vs `Series A` (#41), unlabelled lines,
  `{common}` alone on a lettered identity.

Limits, accepted (fail toward keep or toward withhold, never toward a new figure on a
plain identity): M1's vocabulary does not see `Class II` or `Non-Voting`, so on a PLAIN
identity such a line can `match` (→ `confirmed`, keep) — which is why a plain identity
never rebinds (r2 #17, #18). A preferred word in an amount caption is taken as another
class even when the column is as-converted (r2 #21): the outcome is withhold, not a
wrong figure. Caption words for notes are not M1 evidence (r2 #20).

**Cells** (r2 #24): a share cell is an amount cell with `shares` set and `percent` unset;
a percent cell has `percent` set. A line's **figure** is defined only when it has exactly
one share cell and its count is a whole number `> 0` (#1–#7): a dash, `*`, `N/A`, `0`, a
fractional count, or several share cells (direct + options + total; before / after
columns, #17) give no figure. M2 never selects a total among components. The whole-number
condition came from the reads (Acceptance 3): Ginkgo `0001628280-25-020648` prints Mark
Dmytruk's Class A as `48.176`, while its own footnote (3) says 48,176 shares. That is a
thousands separator typed as a decimal point.

## Decision per `(instrument, accession, holder)` with a legacy row

Population: every legacy row. An instrument with zero or several sec CIKs has no
siblings and is decided `keep` (`abstained:cik`), counted (r2 #33). First applicable step
wins.

1. Instrument blocked (above) → **shipped**.
2. `(instrument, accession)` withheld by slice 2 / 2b this run → **withhold**
   (`other_class:non_common_instrument`).
3. The body is missing, or M1 reported any table error → **keep** (`abstained:body`,
   r2 #34). If no line of the body carries a designator or `preferred`, the result is
   **keep** (`abstained:no_class_evidence`). This is a shortcut and changes no exposure:
   with no such evidence no line can be `mismatch`, so steps 4–7 could only return keep
   or confirmed. It also avoids a cover resolution for every such row; the census's
   `outcome × reason` table prints how many rows that is.
4. No common identity → **keep** (`abstained:identity`).
5. Legacy shares NULL → **keep** (`abstained:no_figure`, #22).
6. No line of the holder → **keep** (`abstained:no_line`; the 516 M1 misses).
7. `S` = the holder's lines holding a share cell whose count equals the legacy shares
   (value provenance, as the shipped `share_locations`, #8, #9; exhaustive over every M1
   occurrence — M1 missing an occurrence is its measured coverage limit, r2 #28).
   - `S` empty → **keep** (`abstained:no_source`).
   - a line in `S` is **match** → **keep** (`confirmed`; legacy percent kept, M2 does not
     re-derive percent, #10).
   - every line in `S` is **mismatch** → the legacy figure is another class's:
     - **rebind** iff the identity is lettered, every line of `S` is in ONE table, and
       exactly one **match** line of the holder sits in that table and has a figure
       (r2 #29, #30). Shares = that figure; **percent = NULL** — no rule here proves a
       percent is percent-of-class rather than of voting power (r2 #25, #26);
     - otherwise **withhold** (`other_class`). The ground is that the legacy figure is
       provably another class's; what the holder's own-class cell says (`—`, `0`,
       several components) only decides that no replacement is known. M2 makes no claim
       that the holder is outside Item 403 (r3 #14; GOOGL Page lands here).
   - otherwise → **keep** (`abstained:ambiguous`).

One outcome per row (#50); no accession-wide fallback (#48). Step 7 has no sibling
witness: the line's own caption is the evidence, and a single-instrument issuer has no
sibling. That is a **changed decision** against slices 3 / 3b, measured below.

Every decision records `BINDING_RULE_VERSION`, the M1 git sha, the cover accession and
title, the slice-2/2b `Suppression` for step 2 (for 2b also the evidence proxy, recomputed
exactly as `extend_by_class` selects it, r3 #15), and per line used `(table_ordinal,
grid_row, group_evidence, first_column of each cell)`. The census output also records the
body's sha256, the ledger snapshot (row count + hash), and per row its inputs: legacy
`(shares, percent)`, sibling symbols and CIK, proxy date, cover pairs (#45, #46, #57, r2
#41, #42, r3 #19).

**Exposure** of a row: `shown(shares, percent)` or `hidden`. Shipped = legacy, hidden
where a ledger row covers it. M2 = keep / confirmed → legacy; rebind → `(figure, NULL)`;
withhold → hidden; shipped → shipped.

## Acceptance (full population, offline except cover fetches)

`scripts/census_2351_binding.py` over every legacy row: M1 lines once per body, one
decision per row. Cover fetches go through `resolve_cover` / `load_cover` and write only
the `sec_cover_12b_*` cache the shipped job writes. Exits non-zero on a failed assertion.

0. **Reconciliation (#56, r2 #32):** the set of decided `(instrument, accession,
   holder)` keys equals the set of legacy keys, each once; every ledger row has ≥ 1
   legacy row (else listed); counts by (outcome, reason) sum to the total (r3 #16).
1. **Exposure diff, every row (#50, #59, #60, r2 #35)**, disjoint categories:
   `same`; `revived` (shipped hidden → M2 shows the legacy figure); `recovered` (shipped
   hidden → M2 shows a different figure); `newly_withheld` (shipped shown → M2 hidden);
   `rebound` (shipped shown → M2 shows a different figure). **Gate: `revived = 0`.**
2. **Changed decisions** counted by (single- vs multi-instrument issuer) × category ×
   reason, listed per accession / holder.
3. **Reads** from the stored primary document AND the cover instance (r2 #39): cells,
   class caption, figure, cover title of the instrument. EVERY `recovered`, `rebound`
   and multi-instrument `newly_withheld`; single-instrument `newly_withheld` all if ≤ 150,
   else every row of each reason stratum below 10 and a persisted, listed random 10 of
   each larger one — a sample, declared as such; the rule's full-population check is gate
   1 (r2 #36–#38). One wrong read → the rule is fixed, the census re-run, and the earlier
   read rows re-checked; the sample list is extended, never re-drawn. Every rebind is
   read, so no replacement figure rests on a sample; the one-cell rule does not prove a
   total (r3 #11–#13) and the reads are that check. Step-2 rows are the shipped slice-2/2b
   decisions, already read in their own PRs; they are not re-read (r3 #18).
4. **Named cases, exact (#54, r2 #40)**, pinned in the census as asserts:
   Alphabet's 2026 proxy (its accession pinned in the PR) — Page is never shown with
   389,051,160 on GOOGL; META `0001326801-25-000040` Zuckerberg on META → `confirmed`
   141,000; LEN `0001193125-26-073504` — Miller's Class B 21,851,560 is never shown on
   the Class A instrument.
5. **Residual:** legacy rows on census multi-class bodies decided `keep`, by reason;
   `confirmed` rows whose `S` also held a mismatch line (#55); proxies of multi-class
   bodies with no common identity.
6. **Identity:** instruments by outcome (lettered / plain / unresolved by cause / no
   cover / blocked).

Unit tests (pure, `tests/test_def14a_binding.py`, #58): every step and branch, incl.
unresolved causes (`Class A-1`, `Classes II and III`, depositary), plain vs lettered,
`Class A` vs `Series A`, multi-cell line (no figure), dash, rebind across two tables
refused, plain identity never rebinds.

M3 does not start until gate 1 passes and every wrong read in 3 is fixed.
